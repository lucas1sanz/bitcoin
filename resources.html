Hardware Wallets

Official documentation, purchase pages, and firmware for the recommended hardware signers.

Coldcard MK4
L2
Open-source, air-gap capable, dual-chip Bitcoin-only hardware wallet by Coinkite. Recommended for serious self-custody.
coldcard.com ↗
BitBox02 (Bitcoin-only)
L2
Fully open-source hardware and firmware with secure element. Made by Shift Crypto in Switzerland. Great UX for beginners moving up.
shiftcrypto.ch ↗
Trezor Safe 3
L2
Open-source hardware wallet with Optiga secure element. Strong choice for those who prefer Trezor's ecosystem. Avoid older Model T for high value.
trezor.io ↗
SeedSigner
L4
DIY stateless air-gapped signing device. Built on Raspberry Pi Zero. Signs PSBTs via QR codes. Nothing persists between sessions.
seedsigner.com ↗
Coinkite Bag Check
L2
Verify the tamper-evident bag serial number on your Coldcard before setup. Ensures supply-chain integrity.
coinkite.com/bag-check ↗

Software Wallets

Desktop and mobile wallet software for managing UTXOs, building transactions, and coordinating with hardware wallets.

Sparrow Wallet
L3
Desktop Bitcoin wallet focused on privacy and control. PSBT, coin control, UTXO labeling, multisig, own node connection. The recommended companion to Coldcard.
sparrowwallet.com ↗
Blue Wallet
L1
Open-source mobile wallet for iOS and Android. Supports on-chain and Lightning. Good starting point for self-custody beginners.
bluewallet.io ↗
Specter Desktop
L3
Open-source desktop wallet with multisig and hardware wallet support. Deep Bitcoin Core integration. Python-based, fully auditable.
specter.solutions ↗
Electrum
L3
Long-running open-source Bitcoin wallet with advanced scripting and multisig support. Power users and developers. Download only from electrum.org.
electrum.org ↗
Phoenix Wallet
L1
Non-custodial Lightning wallet by ACINQ with automatic channel management and splicing. Best Lightning UX for beginners.
phoenix.acinq.co ↗

Node Software

Full node implementations and node-in-a-box platforms for transaction validation and privacy.

Bitcoin Core
L3
The reference Bitcoin full node implementation. Maximum control. Requires manual setup. Verify the download signature from bitcoincore.org — never from a third party.
bitcoincore.org ↗
Umbrel
L3
Docker-based node-in-a-box with a web UI. Runs Bitcoin Core + LND (Lightning). Easiest path to running your own node. App store includes Fulcrum and Electrs.
umbrel.com ↗
RaspiBlitz
L3
Terminal-based Bitcoin + Lightning node on Raspberry Pi. Highly configurable, excellent for learning. Runs Fulcrum, LND or c-lightning. Strong community.
raspiblitz.org ↗
Fulcrum (Electrum Server)
L3
Fast Electrum protocol server for Sparrow Wallet. Optimized for SSD. Recommended over Electrs when you have adequate RAM (4GB+).
github.com/cculianu/Fulcrum ↗
mempool.space
L1
Open-source Bitcoin block explorer and mempool visualizer. Check fee rates before transactions. Can connect to your own node for maximum privacy.
mempool.space ↗

Metal Seed Backups

Fire- and flood-resistant physical seed storage solutions.

Cryptotag Zeus
L3
Grade 5 Titanium seed backup with letter punches. Highest fire resistance (1668°C melting point). Best for long-term or multi-generational storage.
cryptotag.io ↗
Cryptosteel Capsule
L3
Stainless steel tile-based capsule. Stores 4-letter BIP-39 abbreviations. Waterproof and corrosion resistant. Popular and widely available.
cryptosteel.com ↗
Blockplate
L3
Most affordable steel seed backup. Center punch dot-matrix system. Requires only a hammer and center punch. Great entry point to metal backup.
blockplate.com ↗

Privacy Tools

Network-level and OS-level privacy tools for Bitcoin users.

Tor Project
L3
The Tor network routes internet traffic through multiple relays, hiding your IP address. Bitcoin Core and Sparrow support Tor natively. Essential for transaction privacy.
torproject.org ↗
Whonix
L4
A desktop OS that routes all traffic through Tor by design. Use for high-value Bitcoin transactions to ensure no IP leakage. Runs in VirtualBox on any host OS.
whonix.org ↗
Tails OS
L4
An amnesic live OS that boots from a USB drive and leaves no trace on the host machine. Useful for one-time high-value transactions on an untrusted computer.
tails.boum.org ↗
BTCPay Server
L3
Self-hosted Bitcoin payment processor. Accept bitcoin for services or products without KYC. Also useful for receiving non-KYC bitcoin income.
btcpayserver.org ↗

BIP Standards Reference

Bitcoin Improvement Proposals relevant to self-custody and security.

BIP-39 — Mnemonic Seeds
L1
Defines the 2048-word list and encoding scheme for mnemonic seed phrases. The standard used by all major hardware wallets. Includes the optional passphrase extension.
BIP-39 on GitHub ↗
BIP-48 — Multisig Derivation
L4
Multi-account hierarchy for deterministic multisig wallets. Defines derivation paths for native segwit multisig (m/48'/0'/0'/2'). Used by Coldcard, Sparrow, and Caravan.
BIP-48 on GitHub ↗
BIP-174 — PSBT
L3
Partially Signed Bitcoin Transactions. Enables hardware wallets to sign transactions without internet access. The format used by Coldcard microSD workflow and Sparrow.
BIP-174 on GitHub ↗
SLIP-39 — Shamir Sharing
L4
Shamir's Secret Sharing for mnemonic codes. M-of-N seed splitting scheme. Supported natively by Trezor hardware wallets. Alternative to Coldcard's XOR splitting.
SLIP-39 on GitHub ↗
BIP-32 — HD Wallets
L2
Hierarchical Deterministic Wallets. Defines how all addresses in a wallet are derived from a single master seed. The foundation of modern Bitcoin wallets.
BIP-32 on GitHub ↗
All BIPs Repository
L3
The complete repository of all Bitcoin Improvement Proposals on GitHub. Primary reference for Bitcoin protocol standards and wallet specifications.
github.com/bitcoin/bips ↗
